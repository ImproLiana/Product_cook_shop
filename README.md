# Buy&Cook

Интернет-магазин продуктовых наборов для приготовления блюд.

Пользователь может выбрать блюдо, посмотреть рецепт,
изменить количество порций и ингредиентов, добавить блюдо в корзину и оформить заказ.

## Функциональность

- каталог блюд
- поиск
- избранное
- корзина
- изменение количества порций
- выбор ингредиентов
- автоматический пересчёт стоимости
- сохранение корзины в localStorage
- оформление заказа
- добавление собственных блюд и идей

## Технологии

HTML, CSS, JavaScript, JSON
